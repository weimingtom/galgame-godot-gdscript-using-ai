## As short as possible, for kimi version
```
我用claude+kimi终于可以生成一个可以运行的godot gdscript 简单galgame引擎（之前是很多次的失败），
基于json格式，诀窍是——不要扩写对话，尽量把游戏过程说得简单，让代码文件数尽可能少，
它就可以生成可以运行的godot代码——我这里只有3个类，不过还是有一个地方运行出错，
```
